# Thumbnail Grid +

Forked from [Thumbnail Grid Fix ("Fast Thumbnails")](https://github.com/era-walk/kde-thumbnail-grid-fix).

## Changes from upstream

- **Fixed thumbnail aspect ratio** — the original used the monitor's aspect ratio, producing extremely short thumbnails on ultrawide displays (e.g. 32:9). Thumbnails now always render at 16:9.
- **Hover selection** — show windows by hovering over them.
